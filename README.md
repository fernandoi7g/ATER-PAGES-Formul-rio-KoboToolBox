# 📋 Formulário de Coleta de Dados - PAGES

## Projeto Amazônico de Gestão Sustentável (PAGES)

Este repositório contém a página web de acesso ao formulário eletrônico de coleta de dados do **Projeto Amazônico de Gestão Sustentável (PAGES)**.

## 🌱 Sobre o Projeto

O Projeto Amazônico de Gestão Sustentável (PAGES) tem como objetivo fortalecer a agricultura familiar, promover a conservação ambiental e contribuir para o desenvolvimento sustentável dos territórios da Amazônia Maranhense.

## 🚀 Publicação no GitHub Pages

1. Crie um repositório público.
2. Envie o arquivo `index.html`.
3. Acesse **Settings → Pages**.
4. Em **Source**, selecione:
   - Deploy from a branch
   - Branch: `main`
   - Folder: `/root`
5. Salve as configurações.

Após a publicação, o site ficará disponível em:

```
https://SEU-USUARIO.github.io/pages-formulario
```
